# Mandatory AI Agent Instructions

This file is the repository-level entry point for AI coding and research agents.

## Required reading before any work
Read these files from the current repository checkout, not from memory:

1. AI_INSTRUCTIONS/GLOBAL_INSTRUCTIONS.md — mandatory for every task.
2. AI_INSTRUCTIONS/RESEARCH_PROTOCOL.md — mandatory for research, investigation, external information, technical analysis, and evidence-based comparisons.
3. AI_INSTRUCTIONS/EXECUTION_PROTOCOL.md — mandatory for coding, development, file changes, testing, debugging, Git operations, deployment preparation, and delivery.

For hybrid tasks, read and apply all three. Also read AI_INSTRUCTIONS/README.md.

## Project context and handoff
Before continuing existing work, inspect the live repository state and relevant project documentation, including README.md, PROGRESS.md, docs/agents/README.md, docs/agents/IMPLEMENTATION_STATE.md, and relevant architecture, roadmap, test, and module documentation.

Treat live GitHub state, source code, tests, and CI evidence as authoritative over stale status statements.

## Mandatory startup verification
Before modifying files, report:
- instruction files actually read and their version;
- repository, base branch, working branch, and current commit;
- project documents inspected and relevant existing work/PRs;
- task type, scope, and acceptance criteria;
- access limitations, assumptions, and required approvals.

Do not claim to have read, tested, inspected, committed, pushed, or deployed anything unless it actually happened.

## Safety and repository workflow
- Work on a dedicated branch or isolated working copy.
- Never commit or push directly to main.
- Open a reviewable Pull Request for changes.
- Do not merge, release, deploy, alter production, or perform irreversible actions without explicit owner approval.
- No real-money trading, exchange order placement, wallet signing, or blockchain transaction submission without separate explicit authorization for the exact operation.
- Never commit secrets, private keys, seed phrases, passwords, tokens, or credential-bearing URLs.

## Documentation and handoff
Follow AI_INSTRUCTIONS/EXECUTION_PROTOCOL.md. Keep docs/agents/IMPLEMENTATION_STATE.md and relevant project documentation current. Finish with evidence-based results, test outcomes, limitations, status, and a concrete handoff.

If any mandatory file cannot be accessed, state that fact. Do not silently replace missing instructions with guesses.
